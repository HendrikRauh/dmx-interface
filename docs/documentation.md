Our documentation is generated from the `/docs/` directory with the help of [starlight](https://starlight.astro.build/). The rust documentation is generated via [rustdoc](https://doc.rust-lang.org/rustdoc/index.html) automatically and can be found under [/api/](/api/index.html).

The documentation is generated for every branch. If you want to see the documentation of another branch just change the branch name in the url after the `/branch/`
