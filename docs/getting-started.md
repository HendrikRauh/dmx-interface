## Steps

### 1. Hardware

Follow [Hardware & wiring](./hardware.md) for all details on wiring etc.
We have a [case](./case.md) you can 3d print if you want to use it.

### 2. Flash the firmware

After you build the dmx-interface you need to flash the firmware onto the board. You can find the instructions regarding flashing
[on the flashing page](./flashing.md).

### 3. Connect

1. Connect to your ChaosDMX via Wi-Fi. The default SSID and password can be found in the
   [Factory defaults](./config.md#factory-defaults).
2. Open the web interface at <http://192.168.4.1>.
3. Change the password, switch to station mode — see
   [Configuration](./config.md).

If you're unsure of the device state, check the
[status LED](./troubleshooting.md#status-led).
