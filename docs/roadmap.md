title: Roadmap
description: Open features and their state, generated from GitHub issues at build time.
slug: roadmap
---

The roadmap lists all [GitHub issues](https://github.com/HendrikRauh/dmx-interface/issues)
labelled `roadmap` at build time — closed issues disappear automatically.
Issues labelled `in-progress` are shown as “in progress”.
Feel free to [contribute](./development.md#contributing).

```issues
label=roadmap
state=true
```
