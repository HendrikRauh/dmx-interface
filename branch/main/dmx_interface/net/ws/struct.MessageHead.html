Struct MessageHead 

Source 
struct MessageHead {
    kind: String<16>,
    id: String<16>,
}
Expand description

First-pass envelope: {"type": "...", "id": "..."} (extra fields ignored).

Internally tagged enums need serde’s alloc buffering, which no_std serde-json-core lacks — so requests are parsed twice from the same slice: the head first, then a typed payload for config.set.
