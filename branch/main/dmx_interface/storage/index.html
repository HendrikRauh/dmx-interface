dmx_interface

Module storage 

Source
Expand description

NVS persistent storage for device configuration and crash reports.

Wraps esp-nvs behind a process-wide singleton so the panic handler can persist a crash snapshot even though the FLASH peripheral is consumed at init time. Every operation runs synchronously (no await inside) and is serialized through NVS_BUSY, which lets the panic handler decide in one load whether the flash is safe to touch right now.
