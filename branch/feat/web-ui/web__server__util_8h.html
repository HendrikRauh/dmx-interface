esp_err_t get_json_body ( httpd_req_t * req,
cJSON ** json_out )

Helper function to read the entire request body and parse it as JSON.

Parameters
[in]reqThe HTTP request object.
[out]json_outPointer to a cJSON pointer that will receive the parsed JSON object.
Returns
ESP_OK on success, ESP_FAIL or ESP_ERR_NO_MEM on failure.

Reads the request body in chunks until the entire content is received, then attempts to parse it as JSON using cJSON. If error occur during reception or parsing, an appropriate HTTP error response is sent back to the client. If successful, the parsed cJSON object is returned via the json_out parameter. The caller is responsible for freeing the cJSON object when done.
