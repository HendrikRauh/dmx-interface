Minimal WebSocket server (RFC 6455 subset) with JSON envelopes.

Reference infrastructure for the web contributor. Speaks unfragmented text frames only (client frames masked, server frames unmasked) and maps JSON messages onto the config surface:

{"type": "config.get", "id": "1"}
{"type": "config.set", "id": "2", "config": {"led_brightness": 128}}
{"type": "system.get", "id": "3"}
{"type": "ping", "id": "4"}
{"type": "reset", "id": "5"}

Replies: {"type": "ok", "id": …, "config"?| "system"? …}, {"type": "pong", "id": …}, {"type": "err", "id": …, "code", "message"}. config.set takes a ConfigPatch — same merge semantics as POST /api/config. Fragmented frames, continuations and binary messages end the session without a close frame (extending that to a close code like 1003 is the contributor’s call).
