Module button 

Source
Expand description

User button (GPIO5, active-low): power-up factory reset and runtime click actions.

One pin, two phases. boot_factory_reset runs first, awaited straight from main before the network task is spawned (but only after a non-software reset — a reboot we triggered ourselves must never re-enter the hold while the button is still down):

PhaseTriggerBehavior
Boot holdheld at power-upLedStatus::Resetting for RESET_HOLD, then storage::clear → solid LED → wait for release → reboot; releasing earlier aborts with LedStatus::Warning
Click actionspresses after bootclassified into ButtonEvents, dispatched from Config::button_actions

Event discriminants are the button_actions map keys (web: ButtonEvent): 0 single click, 1 double click, 2 multiple (3) clicks, 3 long hold. The action is read from NVS on every event, so the web UI can rebind clicks without a reboot.
