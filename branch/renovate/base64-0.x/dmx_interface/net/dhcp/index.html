Module dhcp 

Source
Expand description

Minimal DHCPv4 server for access-point clients.

Implements the RFC 2131 subset needed to hand out addresses from a fixed pool: DISCOVER → OFFER, REQUEST → ACK/NAK, plus DECLINE, RELEASE and INFORM. Clients are identified by their hardware address (chaddr); every lease slot owns a stable pool address, so a reconnecting device keeps its previous address.

Replies are broadcast while the client has no address of its own (sender 0.0.0.0 or the RFC 2131 broadcast flag) and unicast for renewals. All packet access goes through the bounds-checked Reader and Writer below — client input is never indexed directly.
