Struct LogRing 

Source 
struct LogRing<const N: usize> {
    state: UnsafeCell<State<N>>,
}
Expand description

Single-producer/single-consumer byte ring with overwrite-oldest policy.

Every operation runs inside one critical section. Positions are logical usize cursors masked into the buffer (size must be a power of two), so wrap-around is just masking and dropping the oldest bytes never moves data.

fn commit(&self, n: usize)

Mark the n most recently peeked bytes as consumed. Values larger than the pending amount consume everything.

Source

fn drain_snapshot(&self, out: &mut [u8]) -> usize

Copy the newest bytes into out, then empty the ring. Returns how many bytes were written (oldest data is dropped first when out is too small).

Bytes before the floor marker are skipped: a snapshot must contain the panic banner plus the log lines that followed the boot-time replay, never the replayed report itself.
