fn apply(
    channel: &Channel<'_, LowSpeed>,

    config_brightness: u8,
    elapsed_ms: u64,
)
Expand description

Applies status to the LEDC channel.

§Arguments

  • channel - The LEDC PWM channel to control.
  • status - The requested status pattern.
  • config_brightness - Config-driven brightness (0–255) for the states that use it (LedStatus::Ok, LedStatus::Warning).
  • elapsed_ms - Milliseconds since the last status change; every period starts over from zero (blink begins on, breathing begins dark).
