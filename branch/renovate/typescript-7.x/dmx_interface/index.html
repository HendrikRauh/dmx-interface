Crate dmx_interface 

Source
Expand description

DMX interface firmware for ESP32-S2 (Lolin S2 Mini).

Current scope: status LED on GPIO7 (LEDC PWM, own embassy task), USB-CDC with esptool auto-reset, ring-buffer logging over the CDC port, panic reports persisted across resets, and a WiFi network stack (AP with DHCP server or station mode, AP fallback).
