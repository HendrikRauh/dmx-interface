Expand description

A debounced digital button input.

Tracks the button state across updates and detects clean press edges, ignoring mechanical bounce within the debounce window.

pub fn update(&mut self, is_low: bool) -> bool

Poll the button state and return true on a clean press edge.

Call this repeatedly (e.g. in a main loop) with the current raw GPIO reading (is_low = true when pressed).

§Arguments
  • is_low - true if the button GPIO is currently active (low).
§Returns

true exactly once per press, after the debounce delay has elapsed since the previous accepted press.
