ChaosDMX

Getting startedDevelopment

ChaosDMX is an open-source DIY DMX512 interface on an ESP32-S2 (Lolin S2 Mini). It is meant to bridge lighting-control software (e.g. QLC+) to stage equipment — fixtures, moving heads, fog machines — over WiFi. The firmware serves the web UI, stores the settings in NVS and joins your network in access-point or station mode; no companion app or cloud service is involved.

Caution

This is a rewrite in rust of our first version which used the Arduino Framework. The legacy Arduino-based firmware lives in the legacy/arduino branch and will not be maintained by us anymore. If you have a bugfix feel free to submit a PR.

Have a look at the roadmap to see what is planned and what is already working in this rewrite.

Feel free to report issues or submit a pull request. We are happy to receive contributions.
