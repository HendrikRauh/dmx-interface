serde adapter: index maps as JSON objects with decimal string keys.

The web UI addresses ports by object key (dmx_ports["0"]), while serde-json-core would emit integer keys as bare digits — invalid JSON that browsers reject. Serializing through String<N> and parsing the keys back keeps both directions valid.
